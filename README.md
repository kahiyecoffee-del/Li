# KKD Aracılık – Orta Doğu

Orta Doğu (Suudi Arabistan, BAE, Katar, Kuveyt, Umman, Irak) için KKD üreticileri ile dağıtıcıları buluşturan komisyonlu satış temsilciliği çalışma dosyaları.

- `kkd-ticaret/01-mesaj-sablonlari.md` – Üretici ve alıcılara mesaj şablonları
- `kkd-ticaret/02-temsilcilik-sozlesmesi-taslak.md` – Satış temsilciliği sözleşmesi taslağı
- `kkd-ticaret/03-linkedin-profil.md` – LinkedIn profil rehberi
- `kkd-ticaret/04-takip-tablosu.csv` – Temas takip tablosu
- `kkd-ticaret/05-uretici-listesi.csv` – Üretici hedef listesi
- `kkd-ticaret/06-linkedin-sirket-sayfasi.md` – LinkedIn şirket sayfası (Bridgeline Sourcing)
